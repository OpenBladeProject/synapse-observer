# Synapse Observer

[English](README.md) | [简体中文](README.zh-CN.md) | Русский

Помогите добавить поддержку вашего Razer Blade в [OpenBlade](https://github.com/OpenBladeProject/openblade-core): соберите сведения о ноутбуке и запишите изменения настроек в Synapse. Сохранить и отправить результаты можно без терминала и локальной копии репозитория.

[Скачайте последний выпуск](https://github.com/OpenBladeProject/synapse-observer/releases/latest), распакуйте ZIP и запустите `SynapseObserver.exe` обычным способом.

<a id="what-you-need"></a>
## Что потребуется

- Windows 11, x64.
- [.NET 10 Desktop Runtime, x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). Он загружается отдельно. Если он отсутствует, Windows предложит ссылку на установку.
- Synapse для записи изменений настроек. Сведения об устройстве можно собрать без него.

Можно собирать сведения о Blade, Blade Pro и Blade Stealth. Доступность записи зависит от способа связи Synapse с ноутбуком. См. [охват моделей](docs/ru-RU/model-coverage.md).

<a id="send-evidence"></a>
## Подготовьте данные

1. Откройте приложение и выберите **Collect device information** («Собрать сведения об устройстве»).
2. Для необязательной записи откройте настройки ноутбука в Synapse. Запустите оба приложения обычным способом под одной учётной записью Windows, выберите **Check recording availability** («Проверить доступность записи») и разрешите наблюдение в этом сеансе. Выберите **Start recording** («Начать запись»).
3. Выберите пункт сбора данных и укажите точное значение настройки, показанное в Synapse. Перед изменением выберите **Begin this step** («Начать этот шаг»).
4. Измените одну настройку в Synapse. Дождитесь завершения синхронизации и появления нового значения, затем укажите его и выберите **I changed it** («Я изменил настройку»). Восстановите точное исходное значение, снова дождитесь завершения синхронизации, проверьте значение в элементах управления и выберите **I restored it** («Я восстановил настройку»).
5. Для незнакомого значения используйте **Other state…** («Другое состояние»). Для пунктов, которые нельзя проверить, выберите **Skip** («Пропустить») или **Setting unavailable** («Настройка недоступна»).
6. Если вы записывали настройки, выберите **Stop recording** («Остановить запись»), затем **Save evidence ZIP…** («Сохранить ZIP с доказательствами»). Архив только со сведениями об устройстве тоже полезен, если запись недоступна или пропущена.

Руководство охватывает производительность, вентиляторы, подсветку и раскладку клавиатуры, светящийся логотип, специальные клавиши, батарею и экран. При необязательной проверке M-клавиш/Fn нажмите указанную клавишу, пока окно сборщика активно. Каждая проверка длится пять секунд. Отдельное нажатие Fn может не создавать входного сигнала, доступного этой проверке. Его видимое поведение всё равно можно описать в пункте Fn key.

См. [содержимое ZIP](docs/ru-RU/capture-contents.md).

<a id="submit-the-zip"></a>
### Отправьте ZIP

1. Проверьте ZIP перед загрузкой на GitHub. Запрос поддержки и вложения общедоступны. Сборщик ничего не загружает.
2. Найдите свой номер модели среди [запросов поддержки устройств](https://github.com/OpenBladeProject/openblade-core/issues?q=is%3Aissue%20label%3Adevice-support). Прикрепите ZIP к подходящему запросу или откройте [форму поддержки нового устройства](https://github.com/OpenBladeProject/openblade-core/issues/new?template=device-support.yml).
3. Укажите название ноутбука, номер модели RZ09, версии BIOS и Synapse, версию OpenBlade, если он установлен, проверенные настройки и всё, что вы пропустили или не смогли записать.
4. В новой форме добавьте ZIP Synapse Observer в раздел **Evidence ZIP** («ZIP с доказательствами»). В существующем запросе прикрепите ZIP к комментарию. Если кнопка **Help add support** («Помочь добавить поддержку») в OpenBlade также сохранила `OpenBlade-identity-report.zip`, приложите и этот файл.
5. Дождитесь загрузки каждого ZIP, затем отправьте форму или опубликуйте комментарий.

<a id="recording-notes"></a>
## Примечания к записи

Вы сами изменяете и восстанавливаете настройки в Synapse. Сборщик наблюдает его работу и сохраняет ваши отметки действий. Запись длится до десяти минут. После остановки оставьте это окно открытым, чтобы записать другие настройки. Если завершение работы наблюдателя не удалось подтвердить, перед следующей записью приложение попросит перезапустить Synapse.

Приложение показывает оставшееся место в текущем ZIP. Когда он заполнится, запись остановится. Восстановите незавершённую настройку и выберите **Save ZIP and continue…**, чтобы продолжить в новой части. Сохраните и отправьте все части вместе. Если пока не удаётся восстановить настройку, выберите **Save partial ZIP only…**.

Дождитесь завершения **Syncing Profiles**, прежде чем менять или восстанавливать другую настройку. Если Synapse завис на синхронизации, остановите запись и сохраните ZIP с частичными данными. Восстановите оставшиеся настройки, когда Synapse снова начнёт отвечать. Частичные данные тоже полезны.

Автоматической загрузки нет. Проверьте ZIP перед отправкой. Обычный набор текста, макросы, ввод мыши, пути устройств и поля серийных номеров в инвентаризации исключаются. Незнакомое или потенциально идентифицирующее содержимое команд опускается; проверенные числовые отчёты и отчёты подсветки могут содержать байты.

Это неподписанная сборка для разработки. В испытаниях на работающем ноутбуке записывались изменения производительности на одном Blade 16; другие ноутбуки и механизмы Synapse ещё требуют проверки. Не отключайте средства защиты. Сопровождающие отдельно рассматривают доказательства и проверяют поддержку; запись не подтверждает, что настройка дошла до прошивки ноутбука.
