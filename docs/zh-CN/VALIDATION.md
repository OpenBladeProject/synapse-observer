## 扩展支持采集，2026-10-14

0.2.0 版新增完整支持要求目录、42 个引导活动、经过审核的灯效和键盘报告语法、提示式特殊按键输入、Windows 支持清单以及架构 v2 贡献 ZIP。合成回归覆盖完整帧保留、未知缓冲区隐私、边界、普通键入排除、重复请求/响应操作 ID、有序及重复操作窗口，以及保守的 feature 覆盖。

在 RZ09-0581 上的一次仅清单运行采集了十条 Blade HID 描述符记录、六条驱动祖先记录、两个显卡、一个内置面板、亮度及 Windows/CPU 详情。Windows 返回了 HDR 能力与活动色彩状态、DRR 状态及可用显示模式。本次运行没有温度区域、LampArray 和运行中的 Synapse 来源信息；EC/MCU 命令、当前 LampArray 帧、VRR 范围和未经审核的报告正文仍为明确缺口。一个为 null 的 WMI 温度行暴露了采集故障；修复跳过 null 行，并隔离各支持分节，使某节失败时仍保留之前的数据。

保存的本地 ZIP 有五个条目和 170 个覆盖叶项。此次仅清单运行不含 feature 观测或特殊按键事件。断开连接的渲染覆盖深色 OpenBlade 配色、品牌、版本标记、活动选择器、Custom 详情和窄宽度。这些检查未附加到 Synapse，也未更改笔记本设置。灯效、徽标、键盘模式、M/Fn 输入和额外调优流程仍需贡献者或有人值守试验；先前散热试验不能验证它们，也不能验证其他 Blade 机型。

## 窗口与按键检查修正，2026-10-14

0.2.1 版移除了面向贡献者的键盘模式声明及模式选择器。引导现有 41 个活动；独立支持草稿仍追踪模式要求。被动模式报告仍可用，按键探测保留 Unknown 模式上下文，不要求用户推断模式。

固定的 640 像素最大高度导致 Windows 最大化后仅占部分屏幕。窗口现已没有高度上限，启动时紧凑，采集清单后扩展一次，除非用户已调整大小。断开连接预览使用真实最大化 WPF 窗口，并在图像旁记录实测边界。在此 150% 缩放显示器上，最大化外部边界为 1721.33 × 1033.33 逻辑像素，工作区为 1706.67 × 1018.67；小幅差异来自 Windows 外部缩放边框。窗口填满工作区，不再受 640 像素限制。这些布局检查未附加 Synapse，也未进行输入探测。

- 经 GET_FEATURE 接收的设置确认仍属设置响应；散热、电池和亮度 ACK 不形成 getter 覆盖。
- 并发 Stop（停止）与 Close（关闭）加入同一次清理。原生停止期间轮询继续，读取器结束后执行一次最终排空。自有测试覆盖成功、失败、取消和标记额度已满。

- 共享环形缓冲区压力使事件留在更大的引擎队列中。自有原生夹具在停止期间通过真实 32 槽共享排空通道传输 128 个已完成响应事件的突发流，无额外损失。缺失消费者测试验证一秒上限及明确计数的损失。真实 DLL 夹具也通过自有启动/停止握手；两个测试都没有设备调用。
- 导出冻结会话，在调用方线程外准备草稿和 JSON，并在草稿间复用操作窗口。确定性的阻塞工作夹具验证准备尚未结束时调用方已返回；另一个验证取消后不留下目标 ZIP。
