# Blade 机型覆盖范围

[English](../model-coverage.md) | 简体中文 | [Русский](../ru-RU/model-coverage.md)

采集器面向整个 Razer Blade 系列。设备信息采集没有机型、代际、SKU、BIOS 或 PID 白名单，会保留实际 Windows 身份和发现的每个 Razer HID 接口，包括不熟悉的 ID、usage page 和报告大小。缺少 Synapse 或无法开始记录时，仍可使用信息采集。

记录通过 Razer USB 厂商标识和总线报告的 Blade 产品描述识别物理笔记本。它观测该笔记本自身的 feature 集合，绝不复制 Blade 16 的接口或报告结构。Pro、Stealth、14、15、16、17、18 及不熟悉的 Blade 名称都有合成发现测试数据。这些数据验证策略，不证明实机兼容性。

记录通过可信的 Razer 签名和组件角色识别已安装的 RazerAppEngine 进程及其 node-rz-hid 模块，不使用版本或文件哈希白名单。新版本是来源信息，不是拒绝理由。如果 Synapse 2、3 或未来其他传输方式不使用这条引擎/模块路径，可能需要另一种观测后端；其清单仍然有用。不要因记录不可用就断定笔记本缺少某项能力。

Feature 报告可能具有不熟悉的长度和命令正文。其时间、API、所选接口、状态及结构仍会保留为证据。在隐私审核确定安全的数据投影前，未知正文仅保留元数据。符合已审核数值语法的完整 91 字节封装可以包含字节；91 字节是导出隐私规则，不是附加观测的要求。若新命令需要更多信息，维护者可能需要安排一次有针对性的后续采集。

观测器仅跟踪 HID feature API。经其他驱动 API 或直接原生系统调用发送的控制不在其覆盖范围内。支持一个物理笔记本上的最多八个 feature 集合，以及最多 4096 字节的报告；根设备不明确或描述符无法访问时，会留下部分清单包。它不会悄悄选择另一个设备或放宽身份检查。

目前的实机试验覆盖一台 Blade 16 RZ09-0581 及经过审核的 Synapse 构建。十秒空闲会话观测到一个完成的 375 字节 HidD_SetFeature 调用，并确认观测器停止。不熟悉的正文未导出。采集器未更改任何设置。其他机型和设置变化仍需贡献者试验；请参阅[验证状态](VALIDATION.md)。
