# Охват моделей Blade

[English](../model-coverage.md) | [简体中文](../zh-CN/model-coverage.md) | Русский

Сборщик предназначен для всего семейства Razer Blade. Сбор сведений об устройстве не ограничен списком моделей, поколений, SKU, BIOS или PID. Он сохраняет фактическую идентичность Windows и каждый обнаруженный HID-интерфейс Razer, включая незнакомые ID, страницы использования и размеры отчётов. Сбор остаётся доступен без Synapse и при невозможности начать запись.

При записи сборщик определяет физический ноутбук по USB-идентификатору производителя Razer и описанию продукта Blade, полученному от шины. Он наблюдает собственные feature-коллекции этого ноутбука, никогда не копируя интерфейс или структуру отчётов Blade 16. Для Pro, Stealth, 14, 15, 16, 17, 18 и незнакомых названий Blade существуют синтетические тестовые данные обнаружения. Они проверяют политику, а не совместимость с реальным оборудованием.

Для записи сборщик определяет установленный процесс RazerAppEngine и его модуль node-rz-hid по доверенным подписям Razer и ролям компонентов. Списка разрешённых версий или хешей файлов нет. Номер новой версии записывается для справки и сам по себе не служит причиной отказа. Synapse 2 или 3 и другой будущий транспорт могут потребовать отдельного механизма наблюдения, если не используют этот путь через движок и модуль; их инвентаризация всё равно полезна. Недоступность записи не означает отсутствие возможности у ноутбука.

Feature-отчёты могут иметь незнакомую длину и тела команд. Их время, API, выбранный интерфейс, статус и структура остаются в доказательствах. Неизвестные тела сохраняются только как метаданные, пока проверка конфиденциальности не определит, какие данные можно безопасно экспортировать. Полные отчёты, соответствующие проверенной грамматике конфиденциальности, могут включать байты: 91-байтовые управляющие пакеты, 375-байтовые матричные кадры и подходящие завершённые 90-байтовые ответы без ID отчёта. Эти структуры — правила конфиденциальности экспорта, а не условия подключения наблюдателя. Для новой команды, которой недостаточно метаданных, сопровождающему может потребоваться отдельный целевой сбор.

Наблюдатель отслеживает только HID feature API. Управление через другие API драйверов или прямые нативные системные вызовы находится вне его охвата. Поддерживаются до восьми feature-коллекций одного физического ноутбука и отчёты размером до 4096 байт; неоднозначные корневые устройства или недоступные дескрипторы оставляют пакет с частичной инвентаризацией. Сборщик не выбирает незаметно другое устройство и не ослабляет проверки идентичности.

Испытания на оборудовании охватывают один Blade 16 RZ09-0581. Выпущенный GUI v0.2.7 записал переход Balanced → Silent → Balanced через Synapse при сохранении режима вентиляторов Automatic. В ZIP сохранены четыре запроса изменения температурного режима, два запроса мощности адаптера и двадцать сопутствующих матричных кадров. Тела шести завершённых ответов остаются скрытыми, поэтому это испытание не устанавливает семантику ответов или контрольное чтение прошивки. Наблюдатель остановил перехватчики без зарегистрированных пробелов записи. Более поздние сборки для разработки также проверяли повторное использование записи, производительность от батареи и сети, вентиляторы, подсветку и поведение клавиатуры, логотип, настройки батареи и элементы управления экраном Windows на этом ноутбуке. Эти испытания не подтверждают все функции или другую модель. Другие модели Blade всё ещё требуют испытаний участников; точные источники и результаты см. в [записи проверок](VALIDATION.md).
